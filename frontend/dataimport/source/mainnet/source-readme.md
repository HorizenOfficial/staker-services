# Staking history, Horizen L3 mainnet

Every staking event and every day's accrued rewards of the ZenStaker `0x6bf7cf29a8bce11aa62cf593d165c244fa4d3e31` on the Horizen L3, from the contract's
deployment (block 21317419, 2026-07-22 10:05:02 UTC) to the chain's final state (block 30504979, 2026-11-05 18:11:02 UTC). Generated by
`scripts/staking_history.py` (`make staking-history`) from the chain itself; do not edit by hand. The L3's nodes and
explorer are being retired, so this file is the record.

- `staking-history.csv`: one table, 23316 rows (1425 deposits, 336 withdrawals, 1346 claims, 20209 daily rows) for
  296 deposits of 275 owners. Import it into a spreadsheet and filter by `owner` and `row_type`.
- `staking-history.json`: the same rows grouped by owner (`rowsByOwner[<owner>]` is a list of rows, each a list in the order
  of `columns`), a per-deposit summary (`deposits`) and the run's metadata and totals (`meta`).
- `summary.txt`: totals, the checks the run passed and one line per day.

## Rows

| `row_type` | One row per | Source |
|---|---|---|
| `deposit` | stake or top-up transaction | `StakeDeposited` event |
| `withdraw` | withdrawal transaction | `StakeWithdrawn` event |
| `claim` | reward claim transaction | `RewardClaimed` event |
| `daily` | deposit and UTC calendar day | `deposits(id)` and `unclaimedReward(id)` read at the day's last block |

A `daily` row is the state at the last block of that UTC day (timestamp 23:59:59; on 2026-11-05 the chain's final state). It is
written for every day on which the deposit holds stake or unclaimed rewards at the end of the day, or accrued rewards
during it. The contract logs no event when rewards accrue, so the day's accrual is derived from two reads:

    rewards_accrued_zen = unclaimed at the end of the day - unclaimed at the end of the previous day + claimed during the day

## Columns

| Column | Filled on | Meaning |
|---|---|---|
| `date_utc` | all | UTC calendar day, `YYYY-MM-DD` |
| `timestamp_utc` | all | UTC time of the row's block, `YYYY-MM-DD HH:MM:SS` |
| `row_type` | all | `deposit`, `withdraw`, `claim` or `daily` |
| `owner` | all | owner of the deposit (lower case); a deposit has one owner for its whole life |
| `deposit_id` | all | the staker's deposit id; one owner can hold several deposits |
| `staked_change_zen` | deposit, withdraw | amount staked (positive) or withdrawn (negative) |
| `rewards_accrued_zen` | daily | rewards the deposit earned during that day |
| `rewards_claimed_zen` | claim | rewards paid out by the claim |
| `staked_balance_zen` | deposit, withdraw, daily | stake in the deposit after the event / at the end of the day |
| `unclaimed_rewards_zen` | daily | rewards earned and not yet claimed, at the end of the day |
| `rewards_cumulative_zen` | daily | all rewards the deposit earned up to the end of the day |
| `paid_to` | claim | address the claim was paid to (the deposit's claimer; usually the owner) |
| `block` | all | L3 block number |
| `tx_hash` | deposit, withdraw, claim | L3 transaction hash |

Amounts are exact decimal ZEN (18 decimals, trailing zeros dropped); a spreadsheet shows about 15 significant digits. An
empty cell means the column does not apply to that row type.

## Reading it

- Rewards an address earned in a period: the sum of `rewards_accrued_zen` over its `daily` rows in that period.
- Balance on a date: `staked_balance_zen` and `unclaimed_rewards_zen` of the `daily` row of that date.
- Totals over the whole history: 12499.999999999999999853 ZEN accrued = 10812.634895634136526346 ZEN claimed + 1687.365104365863473507 ZEN unclaimed at the final
  block; 121011.787884294402190778 ZEN staked at the final block.
- The stake and the unclaimed rewards of the last day (2026-11-05) were paid out on Base by the wind-down distribution of 2026-11-20 (Base transaction
  `0x6a5373e35e8e328c667fd3ea6ac259cf0e41ba5c88fae52667ae37e1ec45219a`), to the owner's own address unless it was held back or
  redirected. Those payments are Base transactions and are not rows of this file.
